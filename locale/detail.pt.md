# Mnemon

Memória persistente e habilidades que evoluem a partir das suas conversas, com Memória de execução, Documentos do projeto e Espaços de memória plugáveis.

Use a barra lateral para gerenciar memórias e habilidades. Configure o plugin nesta página.
