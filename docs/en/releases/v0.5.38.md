# v0.5.38: Quieter Conversation Switching and Reliable Idle Review

[简体中文](../../zh-CN/releases/v0.5.38.md) | **English**

This patch release includes #520 and #527–#534.

- **Conversation switching:** pause background reads while memory panels or the browser document are hidden, retain unchanged Source bindings, and share identical pending automatic inspections. Skill activity waits until history rendering has had a chance to finish and reuses completed empty results. Explicit refreshes, successful writes and temporary-history recovery remain fresh (#530, #534; fixes #526).
- **Guarded idle review:** check the current session's completion-tool access before reserving an attempt or starting a child. Blocked or approval-requiring tools skip automatic review without model work; later eligible turns retry after access recovers (#533; fixes #525).
- **Review and Source lifecycle:** optional persistent idle-review quotas and cooling time survive restarts. Named Source tool families follow live Source registrations, and automatic review skips when no applicable write target remains (#531, #532).
- **Small-screen use:** coarse-pointer controls have larger touch targets; narrow memory panels use a compact header and collapsible ordinary notices. Explicitly disabled Sources disappear from navigation and return when enabled (#520, #528, #529).
- **ByteRover on Windows:** resolve and launch the npm CLI without shell quoting, including local npm shims resolved from the working directory (#527).

## Upgrade and compatibility

Use **Memory System → Status → Check versions → Update**, then restart DSH. For an exact WebUI installation:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.38
```

The release acceptance covers DSH **0.2.0-rc.2**, **0.2.1-rc.2** and **0.2.1-rc.3**, both fresh installation and upgrade from v0.5.37. Existing memory data needs no migration. Persistent review watermarks are opt-in and use a separate state file; unavailable or damaged state pauses automatic review with recovery guidance. Manual review and explicit refresh remain available under their existing permissions.

The Source client additions are optional: retained panels default to active, and callers opt into automatic-read sharing. Upgrade through the Starter's exact component pins. Roll back using the previous Starter's complete pinned composition.
