# v0.5.40: Same-turn Document Editing and Published RC1 Support

[简体中文](../../zh-CN/releases/v0.5.40.md) | **English**

- **Immediate Document corrections:** an authorized manage Action can update a Document created earlier in the same execution. Pinned reads and other executions' authority remain unchanged, including delegated executions sharing one View (#562; fixes #559).
- **Visible strategy maintenance:** Memory System explains when the current Strategy does not drive idle review or runtime capacity maintenance, including General. Settings retain saved choices and explain when they take effect (#560; fixes #557).
- **Clear Document destinations:** conversation tools follow the session workspace; ordinary subagents inherit it. Changing a command directory does not choose another project's store. The guide explains how to choose the intended workspace (#561; fixes #558).
- **Unsupported Source diagnostics:** the Layered Strategy names available Sources whose roles it does not admit, while retaining its admission rules. General is the supported alternative for those roles; explicit selection does not bypass the restriction (#552; supports the diagnostics part of #504).
- **Skills scrolling:** the source list and editor scroll independently within their panes, preserving navigation on desktop and narrow layouts (#555; fixes #553).
- **Published DSH RC1:** verify official npm DSH 0.2.2-rc.1 without disabling standalone tasks. Retain older-Host regression coverage (#556; references #554).

## Upgrade and compatibility

Use **Memory System → Status → Check versions → Update**, then restart DSH. For an exact Web-profile install:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.40
```

Existing memories and settings need no migration. General still intentionally opts out of automatic maintenance. The Documents Source requires `dsh-mnemon ^0.5.40` for execution-local creation tracking; install the Starter's complete pinned composition.

Published DSH **0.2.2-rc.1** requires Node >=24.9.0; this release uses **Node 24.22.2** for current RC acceptance. The pinned development baseline remains **0.2.1-rc.5**, with retained checks for **0.2.0-rc.2**, **0.2.1-rc.2** and **0.2.1-rc.3**. See [compatibility](../reference/compatibility.md) for exact scope and Node requirements.

DSH 0.2.2 alpha versions are no longer compatibility or CI targets; upgrade to published RC1. Arbitrary unpublished DSH source builds, native Desktop OS integrations and live cloud-account quality are outside this acceptance. The source-only report #554 remains separate from verified RC1 support.
