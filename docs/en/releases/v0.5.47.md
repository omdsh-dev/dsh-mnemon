# v0.5.47: Clearer Settings and Optional Memory Controls

[简体中文](../../zh-CN/releases/v0.5.47.md) | **English**

- **Clearer, more consistent UI:** consolidate plugin settings, simplify interface copy, align DSH controls, and improve narrow layouts, keyboard navigation, dark mode and reduced motion. Existing Source settings remain available with older Core compositions (#648, #649, #652, #653).
- **Less repeated frontend work:** share stores and subscriptions, use public DSH APIs with older-Host fallbacks, and reduce repeated RPCs, session remounts and graph refreshes. Host configuration and plugin lifecycle handling are consolidated (#645–#647).
- **Reliable archive evidence:** Holographic duplicate-write receipts preserve exact stored evidence even when ranked search omits it (#659; fixes #657).
- **Correct language and tool hints:** Source pages respect custom locale packs and use English for other non-Chinese locales. Each Agent receives hints for the memory tools actually available to it (#660, #661; fixes #644, #656).
- **Conservative automatic capture:** attended-turn guidance follows the same durable-memory criteria as idle review, while retaining explicit user writes and eligible destinations (#662; fixes #655).
- **Optional skill creation directories:** configure the default and offered creation roots for Skills, evolution and marketplace installation. Existing defaults and directory guards remain (#663; closes #658).
- **Optional deferred Runtime details:** keep unpinned low-priority memories out of the initial projection and make them retrievable through a bounded branch-scoped snapshot search. Pinned memories and normal/high-priority projection stay unchanged. Disabled by default (#664; closes #364).
- **Optional memory write approval:** request DSH approval before model-facing Mnemon memory-tool mutations, including native and PTC calls. Each write needs its own approval; rejection or unavailable approval prevents execution. Enabling it pauses idle review. Disabled by default (#665; closes #140).

The four unchanged Providers (Hindsight, Honcho, Mem0 and Mnemon Native) retain their published versions. Storage formats and existing data remain compatible. Both new Runtime deferral and memory-write confirmation settings default to off.

Write confirmation covers model-facing Mnemon memory tools, not manual UI edits, CLI/RPC, shell commands, Git sync or independent Skills automation. It does not revoke an already approved or in-flight operation. Approving an operation also authorizes its normal capacity-maintenance workflow. Custom Strategies need to retain the offered Runtime search route to use deferred details.

The [release acceptance](../../pr-assets/release-v0.5.47/README.md) records fresh installation and upgrade checks against published DSH Hosts. Alpha and arbitrary source builds are not compatibility promises. See [compatibility](../reference/compatibility.md).
