# v0.5.41: DSH Task Compatibility and Reliable Skill Drafts

[简体中文](../../zh-CN/releases/v0.5.41.md) | **English**

- **DSH task compatibility:** adapt to the removed Agent ownership and activation interfaces in the unmodified source snapshot `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`, which the latest #554 reporter identified. Retain the official npm **0.2.2-rc.1** path and real memory agents, model selection, cancellation and isolation (#567; references #554).
- **Continue completed tasks:** a new message sent directly by the user can query, write, delegate and archive from a completed memory task's history, using current workspace and memory permissions. The original result callback stays closed; automatic notices cannot reopen it or replay the old parent instruction (#567).
- **Reliable skill drafts:** draft-only output budgets default to **32,768** tokens initially and **65,536** for one fresh-task retry after a typed truncation. Configure both in Skills settings. Truncation and file-validation correction share a maximum of two attempts; incomplete output is never saved, cancellation is respected, and installed skills still require explicit adoption (#571; fixes #570).
- **Valid suggestion navigation:** deleting a skill suggestion removes its links from reviews, annotations and trajectories while preserving their evidence. Old dangling references are filtered on read without rewriting data; missing suggestion details show a clear message and other read errors can be retried (#566; fixes #565).

## Upgrade and compatibility

Use **Memory System → Status → Check versions → Update**, then restart DSH. For an exact Web-profile install:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.41
```

If the source-build failure in #554 prevents the Memory System page from opening, run the exact Web-profile command above, then restart DSH. This CLI path updates an already-installed bundle; the Plugins page instead requires uninstalling it before adding another version. Existing memories and settings require no migration. Provider output limits may require lower draft budgets; setting the retry budget no higher than the initial budget disables budget expansion.

Official support retains **0.2.0-rc.2**, **0.2.1-rc.2**, **0.2.1-rc.3**, **0.2.1-rc.5** and **0.2.2-rc.1**. RC1 requires Node >=24.9.0. The exact source snapshot above has additional acceptance; this does not cover arbitrary master or alpha builds or the reporter's original Windows installation. See [compatibility](../reference/compatibility.md).

On the newer source snapshot, standalone tasks use ordinary Host session records discoverable through ACP. Its WebUI can hide non-current blank records, so a background task is neither guaranteed silent nor guaranteed a new visible sidebar entry. Direct reads/searches do not create task sessions. Reopening a cold child still follows the Host's requirement to load its parent first. [Task compatibility and continuation evidence](../../pr-assets/dsh-master-agents/README.md) records the detailed boundaries and live-model results.
