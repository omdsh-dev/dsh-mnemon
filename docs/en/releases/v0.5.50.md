# v0.5.50 · Clearer Settings and Memory Workbench

[简体中文](../../zh-CN/releases/v0.5.50.md) | **English**

- Group related settings, show values in collapsed sections, and open component details in a dialog (#697).
- Refine the Memory Spaces overview, the 2D/3D controls and narrow-window layouts. The 3D graph caches theme colors and node display data so dragging and zooming require less work (#698).
- Keep the selected workbench tab visible in a narrow window and let Status cards open their Source pages. Refine Runtime Memory, Project Documents and Skills, and prevent repeated Skills reads when the view rerenders (#699).

## Upgrade

Update from **Memory System → Status → Versions → Update**, then fully restart DSH.

| Package | Version |
| --- | --- |
| `dsh-mnemon` | 0.5.50 |
| `dsh-mnemon-source-documents` | 0.6.3 |
| `dsh-mnemon-source-memory-spaces` | 0.5.31 |
| `dsh-mnemon-source-runtime` | 0.5.23 |
| `dsh-mnemon-source-skills` | 0.5.16 |

On narrow screens, the Memory Spaces overview hides the last full sync time after loading. If several Runtime Sources are installed, use the instance selector on the Runtime Memory page to choose which one to edit.
