# v0.5.49 · On-demand Memory and Reliable Idle Review

[简体中文](../../zh-CN/releases/v0.5.49.md) | **English**

- Add opt-in BM25 recall for individual working-memory entries and Project Document titles in Layered conversations (#693).
- Offer an opt-in DSH compaction backend. Ordinary memory corrections and removals append to preserve the request prefix. Compaction filters old Runtime projections and BM25 quotations. Lost read authority retires affected content before the next model request (#686, #693).
- Preserve branch-scoped Runtime entries during capacity maintenance. Apply sidebar edits, pins and removals to the selected scope. Repair writes when older data contains duplicate entries within one scope (#681, #684, #685).
- Show the user-profile scope in workspace Storage settings and link to the selector for shared USER.md (#682).
- Recover idle review after watermark errors and accept successful review results with no Memory Space IDs. Automatic spawn reviews use DSH-managed sessions on rc.5. Turn off silent review to keep automatic reviews visible under the original conversation (#683, #688, #694).
- Shorten Runtime instructions when a View offers reads only (#695).

## Upgrade and compatibility

Update through **Memory System → Status → Versions → Update**, then fully restart DSH.

| Package | Version |
| --- | --- |
| `dsh-mnemon` | 0.5.49 |
| `dsh-mnemon-source-runtime` | 0.5.22 |
| `dsh-mnemon-source-documents` | 0.6.2 |
| `dsh-mnemon-strategy-default-three-tier` | 0.5.15 |

The experimental BM25 setting and the optional compaction backend both require opt-in. Automatic spawn review is silent by default; the independent switch is in Layered strategy settings.
