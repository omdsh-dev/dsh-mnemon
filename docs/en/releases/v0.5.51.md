# v0.5.51 · Shared storage and optional index recall

[简体中文](../../zh-CN/releases/v0.5.51.md) | **English**

- With workspace storage, Project Documents and Memory Spaces can each be shared across workspaces while working memory stays workspace-local. Both follow the current storage scope by default. Switch back to access data in its original directory. Pack exports and Git sync cover one storage root at a time. (#708)
- The off-by-default experimental index push option in Runtime Memory settings uses BM25 to find a limited set of relevant Project Documents and Memory Spaces index entries for the current turn. (#707)
- The Runtime Memory status now finds USER.md in the global root when the profile is shared. (#706)
- Errors during idle review checks now skip the review safely and let the DSH Host continue serving conversations. (#705)

## Upgrade

Open **Memory System → Status → Versions → Update**, then fully restart DSH.
