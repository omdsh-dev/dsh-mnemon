# v0.5.48: Reliable Activation and Quieter Memory Tasks

[简体中文](../../zh-CN/releases/v0.5.48.md) | **English**

- **Reliable optional enhancements:** consolidate a redundant stock strategy bundle so enabling Light context, Scoped or Auto capture does not immediately dispose it. Preserve installed dependencies, user overrides and custom bundles (#676; fixes #673).
- **Cordis root compatibility:** recognize symbol-based application root metadata without invoking the restricted legacy `root` service. Older published Hosts retain their existing path (#675; fixes #674).
- **Quieter background tasks:** archive newly finished internal task shells where the Host supports it, and isolate automatic spawn-based idle review from the conversation's subagent list. Keep pinned or human-continued conversations and persisted history (#667).
- **Useful continued-task titles:** refresh the original internal title when a user continues a task conversation, while preserving explicit renames (#671; fixes #670).
- **Skill bundle evolution:** include bounded supporting text files in skill drafts, comparison and adoption, with path and stale-version checks (#668; closes #654).
- **Skill size guidance.** Evolution reviews show file sizes and the existing 64 KiB write limit. When a bundle draft exceeds the limit, its single retry can move details into reference files. Manual saves report the size and limit so the author can edit the draft (#677).
- **Optional 3D overview:** switch the Memory Spaces overview graph to a lightweight 3D canvas. The existing 2D view remains the default; search, selection and memory contents retain their behavior (#669; closes #506).
- **Hindsight bank isolation:** document and verify separate writes for two explicitly configured banks (#672; addresses #434).

## Upgrade and compatibility

Update through **Memory System → Status → Check versions → Update**, then fully restart DSH. This release advances only these packages:

| Package | Version |
| --- | --- |
| `dsh-mnemon` | 0.5.48 |
| `dsh-mnemon-source-memory-spaces` | 0.5.30 |
| `dsh-mnemon-source-skills` | 0.5.15 |

The other 16 components keep their published versions. Existing configuration and memory formats remain compatible. Light context is an enhancement, not a main strategy: retain Layered or General as the main strategy and enable Light context separately.

DSH 0.2.2-rc.4 passed the installed-Host regression suite and the Web install and upgrade checks on Node 24.22.2.

The Cordis fix covers the reported API shape from a source build; it does not extend support to arbitrary master builds or alpha releases. [Release acceptance](../../pr-assets/release-v0.5.48/README.md) records the tested artifacts and environments; [compatibility](../reference/compatibility.md) describes the supported Host boundary.
