# v0.5.44: Safer Skill Automation and Clearer Memory Controls

[简体中文](../../zh-CN/releases/v0.5.44.md) | **English**

- **Reliable idle review:** run tool admission inside an open DSH step, keeping later Auto tool review and session history usable. Copy-only recovery also handles affected older histories (#603; fixes #602).
- **Windows Git sync:** recover disposable mirrors blocked by read-only Git pack files, without touching memories or linked external targets (#604; fixes #601).
- **Linked skills stay read-only:** keep viewing, invocation and evaluation available while blocking upstream-file edits and automatic evolution writes (#605; fixes #600).
- **Short plugin introduction:** show a concise localized introduction and documentation links above the existing plugin settings (#606).
- **Memory composer:** collapse the chat composer by default in Memory tabs, remember your preference, and keep drafts and attachments when restoring it. Normal chat and pending interactions retain their controls (#607; fixes #597).
- **Bounded automatic skill adoption:** default to two automatic candidates per calendar day when automatic adoption is enabled; configurable limit and timezone, persistent deduplication, and visible evidence-based suggestion grouping. Zero pauses automation; manual work remains available (#608; closes #598).
- **Embedding credentials:** new keys use DSH credential references instead of profile text. Existing inline keys remain usable until explicit migration; environment-variable references are also supported (#609; fixes #599).

## Upgrade and compatibility

Use **Memory System → Status → Check versions → Update**, then restart DSH. Upgrade the complete Starter composition. Existing memories are retained and automatic skill adoption remains off by default. DSH owns credential-store protection; this release does not claim OS-keychain encryption. Existing profile copies and backups are not erased. After migrating a key, older Mnemon releases that cannot resolve credential references need a compatible configuration or unmanaged CLI environment; see [operations](../guides/operations.md).

```sh
dsh plugin --profile web add dsh-mnemon@0.5.44
```

Supported published Hosts remain **0.2.0-rc.2**, **0.2.1-rc.2 / rc.3 / rc.5**, and **0.2.2-rc.1**. RC1 requires Node >=24.9.0. Arbitrary alpha/master revisions are outside the compatibility claim. See [compatibility](../reference/compatibility.md) and the exact environments in [release acceptance](../../pr-assets/release-v0.5.44/README.md).
