# v0.5.43: Reliable Skill Automation and Pinned Runtime Memories

[简体中文](../../zh-CN/releases/v0.5.43.md) | **English**

- **Recoverable skill work:** interrupted or overdue draft generation and backtests return to a recoverable state. Cancellation prevents late writes; bounded queues and regeneration restore progress (#589, preserving the original contribution in #576; fixes #587).
- **Pinned Runtime memories:** manually pin or unpin entries. Maintenance retains their exact content and scope; the default and general Strategies reserve their projection within the existing View budget. Per-target quotas keep pinned context bounded (#590; closes #515).
- **Optional automatic skill adoption:** disabled by default. New automatic suggestions can be adopted only after complete, fresh paired evaluations with no aggregate, case or check regression. Missing evidence, conflicts or exhausted bounded rewrites leave manual review available (#591; closes #551).
- **Optional subagent Runtime inheritance:** disabled by default and controlled in Runtime settings. Enabled children receive the parent snapshot captured for their turn; existing captured turns remain stable (#585; fixes #583).
- **Native semantic recall:** rank a bounded candidate pool by actual semantic similarity before selecting results. Keep legacy ordering when embeddings are absent and retry only the specific unsupported verbose-flag case (#586; fixes #577).
- **Windows CLI discovery:** find supported pnpm/nvm global locations and statically inspect verified shims without relying on Desktop PATH. Preserve direct process execution and literal arguments; update pnpm installations through pnpm (#593; fixes #588).

## Upgrade and compatibility

Use **Memory System → Status → Check versions → Update**, then restart DSH. Existing memories and settings require no manual migration. Subagent Runtime inheritance and automatic skill adoption remain opt-in. Update the complete Starter composition: Runtime, the default Strategy and the general Strategy now require the new Starter SDK (`dsh-mnemon ^0.5.43`) for pinned memories. Older writers may omit pin metadata.

```sh
dsh plugin --profile web add dsh-mnemon@0.5.43
```

Official supported Hosts remain **0.2.0-rc.2**, **0.2.1-rc.2**, **0.2.1-rc.3**, **0.2.1-rc.5** and **0.2.2-rc.1** (RC1 requires Node >=24.9.0). Additional source-build acceptance is limited to unmodified `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`; it does not claim support for arbitrary master or alpha revisions. See [compatibility](../reference/compatibility.md).
