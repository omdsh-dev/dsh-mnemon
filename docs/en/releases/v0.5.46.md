# v0.5.46: Reliable Memory Tasks and Workspace Controls

[简体中文](../../zh-CN/releases/v0.5.46.md) | **English**

- **Stable skill groups:** collapsed directories stay collapsed when the catalog refreshes. Search results and directly selected skills still reveal their groups (#630; fixes #627).
- **Optional quiet graph:** reduce graph decoration and emphasize the selected node's neighbors. The existing presentation remains the default; the preference is local to the browser (#631; closes #628).
- **Bounded session reads:** avoid repeatedly rebuilding long session histories while preserving historical activity used by memory workflows (#633; fixes #632).
- **Reliable memory-child startup:** install the scoped tool guard, continuation and lifecycle observers before other serial creation listeners can interrupt initialization (#634; fixes #629).
- **Review admission recovery:** retry a transient first-step admission failure within a fixed bound and expose redacted access diagnostics. This improves the reported restart scenario but does not claim its exact cause has been fully reproduced; #635 remains open (#637).
- **Completion-output recovery:** allow the same owned child one correction when its completion JSON is malformed. Strict validation and already committed writes are preserved; the whole task is not restarted (#638; fixes #636).
- **Optional workspace exclusion:** configure exact workspace paths in Storage settings to stop subsequent Mnemon context, tools, automatic review and writes for those workspaces and their children. Existing data remains readable. Removing an exclusion restores participation; the default empty list preserves current behavior (#639; closes #613).

- **Readable capacity failures:** Source capacity errors still trigger automatic maintenance after serialization or realm changes. Failures include the capacity/archive cause and bounded routing diagnostics rather than `[object Object]`. Limits, eligible destinations, exact archive verification and cancellation rules are unchanged (#642; fixes #641).

## Upgrade and compatibility

Update through **Memory System → Status → Check versions → Update**, then fully restart DSH. This release updates:

| Package | Version |
| --- | --- |
| `dsh-mnemon` | 0.5.46 |
| `dsh-mnemon-source-runtime` | 0.5.20 |
| `dsh-mnemon-source-memory-spaces` | 0.5.28 |
| `dsh-mnemon-source-skills` | 0.5.13 |

The other 15 plugins retain their published versions. Storage formats and existing feature defaults are unchanged. Workspace exclusion affects subsequent participation: it does not erase conversation history or roll back operations already dispatched to a Provider, and it is not a filesystem sandbox.

Published DSH 0.2.2 RCs and the documented older Hosts are covered by the [release acceptance](../../pr-assets/release-v0.5.46/README.md). Alpha and arbitrary source builds are not compatibility promises. See [compatibility](../reference/compatibility.md).
