# v0.5.48: 更可靠的激活与更安静的记忆任务

**简体中文** | [English](../../en/releases/v0.5.48.md)

- **可靠启用可选增强：**合并重复的标准策略 bundle，避免轻量上下文、范围隔离或自动捕获刚启用就被销毁；保留已安装依赖、用户覆盖配置及自定义 bundle（#676；修复 #673）。
- **Cordis 根上下文兼容：**识别 Symbol 形式的应用根元数据，避免访问受限制的旧 `root` 服务；较早的正式 Host 继续使用原路径（#675；修复 #674）。
- **减少后台任务干扰：**在 Host 支持时归档刚完成的内部任务会话，让默认 spawn 模式的自动空闲整理不再占用当前对话的子 Agent 列表；保留置顶、用户接续的会话及磁盘历史（#667）。
- **接续任务标题：**用户继续内部任务对话时，按新话题更新原始内部标题，并保留用户主动重命名（#671；修复 #670）。
- **技能文件演进：**技能草稿、差异比较和采纳支持有边界的辅助文本文件，并校验路径及版本是否过期（#668；支持 #654）。
- **技能超限提示。** 演进评审显示文件大小和现有的 64 KiB 写入上限。目录型技能的草稿超限时，已有的一次重试可将细节拆入参考文件。手工保存会提示实际大小和上限，方便作者调整（#677）。
- **可选 3D 概览：**记忆空间概览图可切换为轻量的 3D Canvas；默认仍为原有 2D 视图，搜索、选择及记忆内容的行为保持一致（#669；支持 #506）。
- **Hindsight bank 隔离：**补充两个显式配置 bank 的独立写入说明及验证（#672；对应 #434）。

## 升级与兼容

通过**记忆系统 → 状态 → 检查版本 → 更新**升级，然后完整重启 DSH。本次仅更新以下包：

| 包 | 版本 |
| --- | --- |
| `dsh-mnemon` | 0.5.48 |
| `dsh-mnemon-source-memory-spaces` | 0.5.30 |
| `dsh-mnemon-source-skills` | 0.5.15 |

其余 16 个组件保留原发布版本，现有配置与记忆存储格式保持兼容。轻量上下文是增强策略：主策略继续选择分层或通用策略，再单独启用轻量上下文。

在 Node 24.22.2 上，DSH 0.2.2-rc.4 通过了已安装宿主回归测试，以及 Web 新装与升级验收。

Cordis 修复覆盖报告中源码构建的 API 形态，不扩大到任意 master 或 alpha 的兼容承诺。[发布验收](../../pr-assets/release-v0.5.48/README.zh-CN.md)记录实测制品与环境，受支持的 Host 范围见[兼容性](../reference/compatibility.md)。
