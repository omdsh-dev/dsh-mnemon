# v0.5.40：同轮档案编辑与正式 RC1 支持

**简体中文** | [English](../../en/releases/v0.5.40.md)

- **同轮修正档案**：获准的管理 Action 可以立即更新同一次执行中新建的档案；不扩大读取范围，也不向共享同一 View 的其他委派执行授予权限（#562；修复 #559）。
- **显示策略维护状态**：General 等策略不驱动空闲审查或运行时容量维护时，记忆系统会明确说明。设置继续保留，并解释生效条件（#560；修复 #557）。
- **说明档案目标位置**：对话工具遵循会话工作区，普通子代理继承父会话工作区。改变命令目录不会改选另一个项目的存储；指南补充了选择目标工作区的方法（#561；修复 #558）。
- **补充未接纳 Source 的诊断**：分层策略会指出角色不受支持的可用 Source，保持准入规则不变。这类角色可使用 General，显式 selection 不会绕过限制（#552；支持 #504 的诊断部分）。
- **修复技能页面滚动**：来源列表与编辑器在各自面板内滚动，保留桌面和窄屏导航体验（#555；修复 #553）。
- **正式 DSH RC1 兼容**：验证官方 npm DSH 0.2.2-rc.1，保留独立任务能力，并继续执行旧版 Host 回归（#556；关联 #554）。

## 升级与兼容

在**记忆系统 → 状态 → 检查版本 → 更新**中更新，然后重启 DSH。Web 配置的精确版本安装命令为：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.40
```

已有记忆和设置无需迁移。General 仍按设计不运行自动维护。Documents Source 的执行内创建记录要求 `dsh-mnemon ^0.5.40`，请安装 Starter 锁定的完整组合。

官方 DSH **0.2.2-rc.1** 要求 Node >=24.9.0，本次当前 RC 验收使用 **Node 24.22.2**。开发基线仍为 **0.2.1-rc.5**，继续验证 **0.2.0-rc.2**、**0.2.1-rc.2**、**0.2.1-rc.3**。具体范围及 Node 要求见[兼容说明](../reference/compatibility.md)。

DSH 0.2.2 alpha 不再作为兼容适配或 CI 目标，请升级到官方 RC1。任意未发布 DSH 源码、原生 Desktop 系统集成和真实云账号质量不属于本次验收。#554 的源码构建报告与已验证的 RC1 支持分别跟踪。
