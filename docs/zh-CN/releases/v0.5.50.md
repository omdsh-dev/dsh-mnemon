# v0.5.50 · 更清晰的设置与记忆工作台

**简体中文** | [English](../../en/releases/v0.5.50.md)

- 归拢相关设置，在折叠分组中显示当前配置摘要，并用弹窗展示组件详情（#697）。
- 改善记忆空间总览、2D/3D 切换和窄窗口布局。3D 图谱缓存主题颜色和节点显示数据，减少拖动和缩放时的重复计算（#698）。
- 在窄窗口中保持当前工作台标签可见，状态卡片可以打开对应的来源页面。调整运行时记忆、项目档案和技能页布局，并减少技能页重新渲染时的重复读取（#699）。

## 升级

在**记忆系统 → 状态 → 检查版本 → 更新**中升级，然后完整重启 DSH。

| 包 | 版本 |
| --- | --- |
| `dsh-mnemon` | 0.5.50 |
| `dsh-mnemon-source-documents` | 0.6.3 |
| `dsh-mnemon-source-memory-spaces` | 0.5.31 |
| `dsh-mnemon-source-runtime` | 0.5.23 |
| `dsh-mnemon-source-skills` | 0.5.16 |

窄屏上的记忆空间总览会在读取完成后隐藏上次全量同步时间。配置了多个运行时记忆来源时，请在运行时记忆页用实例选择器确认要编辑的实例。
