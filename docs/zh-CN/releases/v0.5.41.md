# v0.5.41：DSH 任务兼容与可靠的技能草案

**简体中文** | [English](../../en/releases/v0.5.41.md)

- **DSH 任务兼容：**适配未经修改的源码快照 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159` 移除 Agent 归属与激活接口的变化；它正是 #554 最新报告者提供的 commit。保留官方 npm **0.2.2-rc.1** 原路径，以及真实记忆 Agent、模型选择、取消和隔离能力（#567；关联 #554）。
- **继续已完成的任务：**用户在记忆任务历史中直接发送新消息后，可按当前工作区和记忆权限查询、写入、委派与归档。原任务结果回调保持关闭，自动通知不能恢复旧权限或让父会话重放旧指令（#567）。
- **可靠的技能草案：**草案独立使用首次 **32,768** token、截断重试 **65,536** token 的默认预算，可在技能设置中修改。只对明确的截断用新任务重试一次，与文件校验修正共用最多两次尝试；不保存不完整输出，尊重取消，修改已安装技能仍需用户明确采纳（#571；修复 #570）。
- **有效的建议入口：**删除技能建议时，移除复盘、标注及轨迹中的关联入口，保留原始证据。旧的失效引用只在读取时过滤，不回写数据；建议已不存在时明确提示，其他读取错误可重试（#566；修复 #565）。

## 升级与兼容性

使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。Web profile 精确安装命令：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.41
```

如果 #554 的源码版启动故障已导致记忆系统页面无法打开，请运行上面的 Web-profile 精确版本命令，随后重启 DSH。此 CLI 路径支持更新已安装的包；若使用插件页面，则需先卸载再添加新版。已有记忆与设置无需迁移。模型提供方的输出上限可能要求调低草案预算；重试预算不高于首次预算时，不扩大预算重试。

官方支持继续覆盖 **0.2.0-rc.2**、**0.2.1-rc.2**、**0.2.1-rc.3**、**0.2.1-rc.5** 与 **0.2.2-rc.1**。RC1 要求 Node >=24.9.0。上述精确源码快照有额外验收，不代表任意 master、alpha 或报告者原来的 Windows 安装环境均已验证。详见[兼容性说明](../reference/compatibility.md)。

在新版源码快照中，独立后台任务使用普通 Host 会话记录，ACP 可以发现；WebUI 可能过滤非当前的 blank 记录，因此不能保证任务始终静默，也不能说每次必然增加可见侧栏条目。直接读取与搜索不会创建任务会话。重启后重新打开冷子任务，仍需按 Host 要求先加载父会话。[任务兼容与续办证据](../../pr-assets/dsh-master-agents/README.zh-CN.md)记录了详细边界及真实模型结果。
