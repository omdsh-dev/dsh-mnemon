# v0.5.51 · 共享存储与可选索引召回

**简体中文** | [English](../../en/releases/v0.5.51.md)

- 使用工作区存储时，项目档案和记忆空间可分别设为全局共享，工作记忆仍按工作区隔离。两者默认跟随当前存储范围。切回原范围即可读取留在原目录的数据。Pack 导出和 Git 同步每次只覆盖一个存储根。（#708）
- 运行时记忆设置新增默认关闭的实验性索引推送，通过 BM25 选出少量相关项目档案和记忆空间索引条目，追加到本轮上下文。（#707）
- 用户画像设为全局共享时，运行时记忆状态从全局目录检查 USER.md，避免误报需要修复。（#706）
- 空闲复盘检查出错时会跳过本次复盘，DSH Host 可继续处理会话。（#705）

## 升级

在**记忆系统 → 状态 → 检查版本 → 更新**中升级，然后完整重启 DSH。

| 包 | 版本 |
| --- | --- |
| `dsh-mnemon` | 0.5.51 |
| `dsh-mnemon-source-documents` | 0.6.4 |
| `dsh-mnemon-source-memory-spaces` | 0.5.32 |
