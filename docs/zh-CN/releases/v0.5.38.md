# v0.5.38：减少会话切换读取与可靠的空闲审查

**简体中文** | [English](../../en/releases/v0.5.38.md)

本补丁版本包含 #520 与 #527–#534。

- **会话切换：**记忆面板或浏览器页面隐藏时暂停后台读取，保持未变化的 Source 绑定，并合并相同的进行中自动检查。技能活动查询让会话历史先获得渲染机会，复用已完成的空结果。显式刷新、成功写入后的更新及历史暂不可用后的恢复仍保持最新（#530、#534；修复 #526）。
- **工具守卫下的空闲审查：**预留次数或启动子 Agent 前，先检查当前会话是否允许使用完成工具。工具被拦截或需要审批时，跳过自动审查且不调用模型；权限恢复后，后续符合条件的轮次会重试（#533；修复 #525）。
- **审查与 Source 生命周期：**可选的持久化空闲审查配额和冷却时间在重启后保留。命名 Source 工具族跟随活动 Source 注册，没有适用写入目标时跳过自动审查（#531、#532）。
- **小屏使用：**粗指针设备的控件点击区域增大；窄记忆面板使用紧凑页头和可折叠的普通提示。明确关闭的 Source 隐藏导航标签，重新启用后恢复（#520、#528、#529）。
- **Windows 上的 ByteRover：**不经 shell 引号解析启动 npm CLI，并支持从工作目录解析本地 npm shim（#527）。

## 升级与兼容性

使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。精确安装 WebUI 版本：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.38
```

发布验收覆盖 DSH **0.2.0-rc.2**、**0.2.1-rc.2** 与 **0.2.1-rc.3**，分别全新安装及从 v0.5.37 升级。现有记忆数据无需迁移。持久化审查水位默认关闭，启用后使用独立状态文件；状态不可用或损坏时暂停自动审查，并提供恢复指引。手动审查和显式刷新仍遵循原有权限。

新增 Source 客户端能力均为可选：保留面板默认处于活动状态，自动读取共享由调用方主动选择。请通过 Starter 的精确组件版本组合升级；回滚时恢复旧 Starter 的完整版本组合。
