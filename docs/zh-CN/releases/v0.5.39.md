# v0.5.39：可靠的记忆回合与新版 DSH 支持

**简体中文** | [English](../../en/releases/v0.5.39.md)

此补丁版本包含 #543–#547 和 #549。

- **已接受回合中的记忆可用性：** 其他插件提前返回提示词组装结果时，在已接受的 Agent 步骤执行前补齐当前 View。原生和 PTC 读取、后续回合、恢复会话及委派子 Agent 保留原有权限边界（#544；修复 #542）。
- **PTC 历史完整性：** 在等待完成的回合停止钩子内检查自动审查准入，并在回合结束前等待执行完成；空闲计时器消费结果，不在父回合结束后执行工具。为受影响的无继承根 v4 会话提供仅生成副本的恢复路径，识别特定成对的回合外探针（#545；修复 #541）。
- **Unicode 活动摘要：** 标题、摘录等有长度限制的活动字段不会再把代理对截成两半。完整记忆正文保持不变，防止新写入的元数据导致后续模型请求失败（#549；修复 #548）。
- **Git 同步作者：** 默认身份优先遵循生效的 Git 配置，再使用历史回退值；自定义身份仍显式生效，安全重试不改写已发布的 Git 历史（#543；修复 #539）。
- **技能草案目标：** 可选择用户范围、项目范围或按存储范围推导；升级默认值仍为用户范围。采纳时的显式选择优先，已有技能写回原位置，项目目标不可用时明确失败，不静默切换根目录（#546；支持 #540）。
- **新版 DSH 契约：** 开发依赖更新至 rc.5，并适配 alpha.2 公开的执行器与工具批调用接口；继续验证较早的受支持版本（#547）。

## 升级与兼容

使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。全新 Web Profile 精确安装命令：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.39
```

兼容矩阵保留 DSH **0.2.0-rc.2**、**0.2.1-rc.2** 和 **0.2.1-rc.3**，以 **0.2.1-rc.5** 为当前 RC 基线，并单独验证 **0.2.2-alpha.2**。RC 与 alpha 都仍是上游预发布版本。在 macOS 上使用 alpha 时，建议采用完整验证过的 **Node 24.22.2**；更早的 Node 24 版本有独立的构建或运行时限制，见[兼容说明](../reference/compatibility.md)。

现有记忆与设置无需迁移。升级会防止新增畸形会话记录，但不会自动修复已有历史。针对特定 PTC 损坏，请按照[仅副本恢复流程](../reference/compatibility.md#ptc-空闲审查历史恢复)保留原始备份，用同一 DSH 版本验证副本后，再进行离线替换。已有 Unicode 损坏会话需单独恢复；新会话仍可继续使用完整的记忆。

回滚应安装上一个 Starter 的完整固定组件组合，也会恢复旧版本的缺陷行为。新的目标设置不会移动现有技能文件。
