# v0.5.46：更可靠的记忆任务与工作区控制

**简体中文** | [English](../../en/releases/v0.5.46.md)

- **稳定的技能分组：**目录折叠状态不会被目录刷新重新展开；搜索结果和直接选中的技能仍会展开其所在分组（#630；修复 #627）。
- **可选的安静图谱：**减少图谱装饰，突出选中节点的邻居。原有呈现仍为默认值，偏好保存在当前浏览器（#631；解决 #628）。
- **有界的会话读取：**避免重复重建长会话历史，同时保留记忆流程使用的历史活动证据（#633；修复 #632）。
- **可靠的记忆子 Agent 初始化：**在其他串行创建监听器可能中断初始化之前，安装作用域工具守卫、继续执行与生命周期监听器（#634；修复 #629）。
- **审查准入恢复：**对首步临时准入失败进行有次数上限的重试，并提供脱敏后的访问诊断。这改善了报告中的重启场景，但不声称已经完整复现其确切原因；#635 保持开启（#637）。
- **完成输出恢复：**子 Agent 的完成 JSON 格式错误时，允许同一受控子 Agent 修正一次。保留严格校验和已提交的写入，不重跑整个任务（#638；修复 #636）。
- **可选的工作区排除：**在存储设置中指定精确工作区路径，停止这些工作区及其子 Agent 后续的 Mnemon 上下文、工具、自动整理和写入。原有数据仍可查看，移除排除项后恢复；默认空列表保持现有行为（#639；解决 #613）。

- **可读的容量错误：**Source 容量错误经过序列化或跨 realm 传递后，仍能触发自动维护。失败时保留容量、归档原因和有界路由诊断，不再显示 `[object Object]`；不改变上限、合格目标、精确归档校验和取消规则（#642；修复 #641）。

## 升级与兼容性

通过 **记忆系统 → 状态 → 检查版本 → 更新** 升级，然后完整重启 DSH。本次更新：

| 包 | 版本 |
| --- | --- |
| `dsh-mnemon` | 0.5.46 |
| `dsh-mnemon-source-runtime` | 0.5.20 |
| `dsh-mnemon-source-memory-spaces` | 0.5.28 |
| `dsh-mnemon-source-skills` | 0.5.13 |

其余 15 个插件保持已发布版本。存储格式和已有功能默认值不变。工作区排除对后续参与生效，不抹除会话历史，不回滚已经派发给 Provider 的操作，也不是文件系统沙箱。

已发布的 DSH 0.2.2 RC 与文档列出的较早 Host 由[发布验收](../../pr-assets/release-v0.5.46/README.zh-CN.md)覆盖；不承诺兼容 alpha 和任意源码构建。参见[兼容性说明](../reference/compatibility.md)。
