# v0.5.47：更清晰的设置与可选记忆控制

**简体中文** | [English](../../en/releases/v0.5.47.md)

- **更统一的界面与设置：** 整合插件设置、精简文案、统一 DSH 控件，改善窄屏布局、键盘操作、深色模式和减少动效体验；独立 Source 与旧 Core 组合时仍保留设置入口（#648、#649、#652、#653）。
- **减少前端重复工作：** 共享状态与订阅，使用 DSH 公共 API 并保留旧宿主回退，减少重复 RPC、会话重挂载和图谱刷新；同时整理 Host 配置与插件生命周期（#645–#647）。
- **可靠的归档证据：** Holographic 的重复写入回执保留已存储的精确证据，避免排序搜索未返回该记录时误判归档失败（#659；修复 #657）。
- **正确的语言与工具提示：** Source 页面尊重自定义语言包，其他非中文语言回退英文；各 Agent 仅收到其实际可用记忆工具的提示（#660、#661；修复 #644、#656）。
- **更保守的自动记忆捕获：** 对话中的捕获提示与空闲整理采用一致的长期价值标准，保留用户明确要求的写入和可用目标（#662；修复 #655）。
- **可配置的技能创建目录：** 为技能创建、自演进和市场安装指定默认目录与可选目录，保留原有默认值和目录校验（#663；解决 #658）。
- **可选的 Runtime 详情延迟加载：** 未置顶的低优先级记忆不再提前注入，Agent 可通过有界的分支快照搜索按需获取；置顶记忆及普通、高优先级记忆保持原有投影行为。默认关闭（#664；解决 #364）。
- **可选的记忆写入确认：** 模型通过原生工具或 PTC 修改 Mnemon 记忆前，请求 DSH 授权；每次写入分别确认，拒绝或无法取得授权时不执行。开启后暂停空闲整理。默认关闭（#665；解决 #140）。

Hindsight、Honcho、Mem0 和 Mnemon Native 四个 Provider 保持已发布版本。存储格式与已有数据保持兼容；Runtime 延迟加载、记忆写入确认均默认关闭。

写入确认覆盖模型调用的 Mnemon 记忆工具，不覆盖手动 UI 编辑、CLI/RPC、Shell、Git 同步或独立的技能自动化，也不会撤销已获批准或正在执行的操作。批准一次操作也授权该操作正常触发的容量维护。自定义 Strategy 需保留 Runtime 提供的搜索路由，才能使用延迟加载的详情。
