# v0.5.43：可靠的技能自动化与固定运行时记忆

[English](../../en/releases/v0.5.43.md) | **简体中文**

- **技能任务恢复：**草案生成、回测中断或超时后回到可恢复状态；取消阻止迟到结果写入，通过有界队列与重新生成恢复进度（#589，保留 #576 原作者提交；修复 #587）。
- **固定 Runtime 记忆：**可手动固定或取消固定。整理保留其原文与作用域，默认和通用策略在现有 View 预算内优先保留投影；按目标设置固定配额，限制上下文占用（#590；解决 #515）。
- **可选的技能自动采纳：**默认关闭。仅对新增自动建议运行，要求完整、最新的成对回测，整体、逐用例和逐检查项均不退步。证据缺失、冲突或有限次重写耗尽时保留人工审阅（#591；解决 #551）。
- **可选的子 Agent Runtime 继承：**默认关闭，在 Runtime 配置中开启。开启后按回合捕获父级记忆快照，已捕获回合保持稳定（#585；修复 #583）。
- **Native 语义召回：**先取有界候选集，按真实语义相似度排序后选取结果；缺少 embedding 时保留原排序，仅针对不支持 verbose 参数的旧 CLI 做兼容重试（#586；修复 #577）。
- **Windows CLI 发现：**支持常见 pnpm/nvm 全局目录，静态识别已验证的 shim，无需依赖 Desktop 的 PATH；保持直接进程调用与参数原义，pnpm 安装使用 pnpm 更新（#593；修复 #588）。

## 升级与兼容性

通过**记忆系统 → 状态 → 检查版本 → 更新**升级，随后重启 DSH。已有记忆与设置无需手动迁移，子 Agent Runtime 继承与技能自动采纳仍需主动开启。请一起升级 Starter 的完整组件组合：Runtime、默认策略和通用策略的固定记忆能力使用新增 SDK，要求 `dsh-mnemon ^0.5.43`。旧版写入方可能丢失固定标记。

```sh
dsh plugin --profile web add dsh-mnemon@0.5.43
```

继续支持 **0.2.0-rc.2**、**0.2.1-rc.2**、**0.2.1-rc.3**、**0.2.1-rc.5** 和 **0.2.2-rc.1**（RC1 要求 Node >=24.9.0）。额外源码验收仅覆盖未修改的 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`，不代表任意 master 或 alpha 版本。详见[兼容性说明](../reference/compatibility.md)。
