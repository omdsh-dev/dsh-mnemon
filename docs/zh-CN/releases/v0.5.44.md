# v0.5.44：更稳妥的技能自动化与记忆交互

**简体中文** | [English](../../en/releases/v0.5.44.md)

- **空闲审查修复：**把工具准入检查放在 DSH 尚未结束的 step 内，避免破坏后续 Auto 工具审查与会话历史；复制修复工具也支持已受影响的旧历史（#603；修复 #602）。
- **Windows Git 同步：**恢复被 Git 只读 pack 文件阻塞的临时镜像清理，不修改记忆或链接到外部的目标（#604；修复 #601）。
- **链接技能只读：**保留查看、调用与评估，阻止手工编辑或自动进化改写上游文件（#605；修复 #600）。
- **简短插件介绍：**插件设置上方改为简短的本地化介绍和文档链接，原有设置继续可用（#606）。
- **记忆页输入框：**默认收起记忆 Tab 中的聊天输入框，记住用户选择；展开时保留草稿与附件，正常聊天和待处理交互保留原有控件（#607；修复 #597）。
- **技能自动采纳限额：**启用自动采纳时默认每天最多两个候选，可配置限额和时区，持久化去重，并按可见证据对建议分组；设为零暂停自动流程，保留人工操作（#608；解决 #598）。
- **Embedding 凭据：**新密钥写入 DSH 凭据存储，配置中仅保存引用；已有明文密钥继续可用，可主动迁移，也支持环境变量引用（#609；修复 #599）。

## 升级与兼容

通过**记忆系统 → 状态 → 检查版本 → 更新**升级，再重启 DSH。请升级完整 Starter 组合。已有记忆保留，技能自动采纳仍默认关闭。凭据存储的保护由 DSH 负责，本次不承诺操作系统钥匙串加密；已有配置副本与备份不会被抹除。迁移密钥后，不支持凭据引用的旧 Mnemon 版本需要兼容配置或不受插件管理的 CLI 环境变量，详见[运维指南](../guides/operations.md)。

```sh
dsh plugin --profile web add dsh-mnemon@0.5.44
```

继续支持正式发布的 **0.2.0-rc.2**、**0.2.1-rc.2 / rc.3 / rc.5** 和 **0.2.2-rc.1**；RC1 要求 Node >=24.9.0。不承诺任意 alpha/master 版本兼容。见[兼容性说明](../reference/compatibility.md)与[发布验收](../../pr-assets/release-v0.5.44/README.zh-CN.md)列明的具体环境。
