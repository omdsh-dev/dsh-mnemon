# v0.5.49 · 按需记忆与更可靠的空闲审查

**简体中文** | [English](../../en/releases/v0.5.49.md)

- 分层策略增加可选 BM25 检索，按需召回单条工作记忆和项目档案标题（#693）。
- 增加可选的 DSH 压缩后端。普通更正和删除采用尾部追加，保留请求前缀。压缩摘要过滤旧 Runtime 投影和 BM25 引用，收回读取权限时在下一次模型请求前清理受影响的内容（#686、#693）。
- 容量整理保留各分支的同文记忆。侧栏编辑、固定和删除只作用于所选范围；修复旧数据在同一范围存在重复条目时的写入问题（#681、#684、#685）。
- 工作区存储设置显示用户画像的实际范围，可直接打开 USER.md 共享范围设置（#682）。
- 水位状态恢复后可继续空闲审查，成功结果允许省略空的记忆空间 ID。rc.5 上自动 Spawn 审查由 DSH 托管，关闭静默即可在原对话的子 Agent 列表中查看审查会话（#683、#688、#694）。
- 当前 View 只有读取权限时，简化 Runtime 指引（#695）。
