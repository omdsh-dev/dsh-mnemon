# v0.5.35：更稳妥的记忆更新与技能评测

**简体中文** | [English](../../en/releases/v0.5.35.md)

本版本汇总 v0.5.34 之后合并的修复与小范围增强。

- **技能管理：**移除的技能可在回收站中查看，并恢复到记录的项目与原始路径。恢复时会检查冲突，支持重命名；明确确认替换后，被替换的技能仍保存在回收站。后台工作结束后会刷新技能卡片。复盘会收到有界的待处理建议上下文，以便复用已有建议并保留先前要求。自进化设置说明任务与子 Agent 会话保留在本地，直到手动删除。
- **评测：**对于纯文本回测无法衡量的用例，可勾选**依赖图片输入**。运行会显示**未测**，不为该用例调用执行或评分模型，也不计入分数、通过率和基线比较。这是显式标记，尚不包含图片执行或自动识别。
- **运行时记忆与同步：**自动替换不会降低已有记忆的重要性。导入和 Git 同步会将超出热记忆预算的记录保存在事务性的本地归档中，避免因此失败或丢弃记录。冲突导入的记忆空间保持停用、使用不同名称，重复合并会复用同一冲突副本。发给模型的运行时快照省略默认注释与监控字段，同时保留非默认元数据。
- **Provider：**OpenViking 写入适配更严格的 0.5 内容 API；关键词检索通过字面量 grep 执行，限定范围与结果数量，并读取完整内容。Holographic 将 1–5 的重要性转换为 0–1 的 trust，未填写重要性时保留 Provider 默认值。召回保留 Provider 原生排序，不再将未经校准的分数视为归一化置信度。
- **宿主与集成：**独立任务继承 DSH 模型时保留配置的推理强度。安装指南解释 DSH 自动加载 bundle patch 的行为，以及重复手动插入后的恢复方式。公开 Host SDK 导出 `canonicalWorkspacePath` 与 `workspaceStorageId`，本次不引入工作区存储迁移。主题可通过 `--mn-block-fill` 设置提示信息块填充色，默认外观保持不变。

## 升级与兼容性

继续支持 DSH **0.2.1-rc.2** 与 **0.2.0-rc.2**。从 v0.5.34 升级，可使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。网页版本的精确安装命令为：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.35
```

更早的安装与桌面应用请参阅[兼容性与升级](../reference/compatibility.md)及[安装指南](../guides/installation.md)。

已有记忆无需迁移。运行时溢出归档保留在本地，不属于删除；其恢复与备份边界见[运行与维护](../guides/operations.md)。技能回收站保留移除的文件，直到明确永久删除。新增评测标记是可选字段，旧用例保持原行为。降级到不识别标记的旧 Host 前，请先停用这些用例，旧 Host 无法保证跳过它们。已有评测记录不变；标记用例后重新运行，才会生成新的未测结果。工作区路径与存储 ID 不变。
