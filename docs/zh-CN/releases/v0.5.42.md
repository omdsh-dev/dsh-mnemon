# v0.5.42：有界运行时快照与可靠的记忆管理

**简体中文** | [English](../../en/releases/v0.5.42.md)

- **运行时快照：**限制模型可见的快照历史；内容不变和符合条件的新增沿用追加方式，保留请求前缀。快照数量/字节超限，或权限及可见事实需要立即清理时，统一建立新快照组（#579；修复 #573）。
- **技能来源：**建议、草案、重写、回测与采纳绑定原技能及工作区。从准确的复盘证据恢复旧建议；无法恢复来源的手工草案保留正文并提示重新生成，避免误改同名文件（#580；修复 #574）。
- **永久删除档案：**确认后移除活跃或归档的托管 Markdown 与索引记录，校验索引/文件修订和 ReadGrant，索引写入失败时回滚，随后刷新列表及统计。不写冷索引，不删除项目原文件（#581；解决 #578）。
- **作用域来源设置：**区分继承默认值和明确不选来源，零来源保存需要确认；保持运行时优先级，允许选择符合条件的能力来源和自定义来源，保留独立写权限限制（#569；修复 #568）。
- **Git 同步压缩包：**解包前拒绝不安全路径、过多条目/过大容量及大小字段不一致的 Stored ZIP 条目，保留有效 Stored/Deflate 压缩包兼容性（#564）。

## 运行时上下文与缓存复用

当前模型可见的 Runtime 快照组最多保留**四份符合条件的完整投影快照 / 64 KiB UTF-8 文本**。内容不变时不追加；符合条件的新增保留已有请求前缀；删除、修正、权限/作用域变化或任一预算超限时建立新快照组。单份当前快照超过预算时仍完整保留。旧快照退出模型上下文，原始会话审计日志保持追加式保存。这些初始阈值用于平衡上下文增长与前缀复用，并非实测最优缓存参数，也不代表已测得云端缓存命中率。

[Runtime 验证](../../pr-assets/issue-573-runtime-snapshots/README.zh-CN.md)记录了真实 Host 请求前缀、快照重建行为与旧记录识别边界。模型提供方的缓存仍是尽力而为，受其自身规则影响。

## 升级与兼容性

使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。Web profile 精确安装命令：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.42
```

已有记忆与设置无需手动迁移。已有会话在下一次运行时清理可识别的历史 Runtime 快照。永久删除档案作用于托管副本和索引。

官方支持继续覆盖 **0.2.0-rc.2**、**0.2.1-rc.2**、**0.2.1-rc.3**、**0.2.1-rc.5** 与 **0.2.2-rc.1**。RC1 要求 Node >=24.9.0。额外验收针对未修改的源码 commit `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`，不代表任意 master、alpha 或报告者的 Windows 环境均已验证。详见[兼容性说明](../reference/compatibility.md)。
