# v0.5.45：可靠的空闲审查与更清楚的技能管理

**简体中文** | [English](../../en/releases/v0.5.45.md)

- **DSH 0.2.2-rc.2：**隐藏记忆快照退役时的空上下文卡片，保留真实记忆快照、审计历史和上下文追加策略（#618）。
- **可辨识的记忆任务：**在支持的 Host 上，用操作类型和唯一后缀命名子 Agent，保留原有任务标签与隔离（#620；修复 #616）。
- **技能分组折叠：**可折叠来源目录，展示路径和数量，搜索匹配与选中技能所在分组会自动展开（#621；解决 #617）。
- **可选的链接技能更新：**在技能设置中主动开启后，编辑、恢复和采纳修改会更新链接指向的原文件，并保留符号链接或 junction；默认关闭（#622；解决 #611）。
- **安静取消空闲审查：**已销毁的 Agent 上下文不再启动审查或安装监听器；没有已提交写入的取消不再报错，真实错误和部分写入回执仍可见（#624；修复 #623）。
- **审查输出预算：**每次模型响应的默认 token 上限从 4,096 提高到 16,384，显式配置的 `idleReview.maxTokens` 继续优先生效（#615）。

## 升级与兼容性

通过**记忆系统 → 状态 → 检查版本 → 更新**升级完整 Starter 组合，然后完全退出并重启 DSH。本次更新 `dsh-mnemon` 至 **0.5.45**、`dsh-mnemon-source-skills` 至 **0.5.12**，其余 17 个插件保持已发布版本。记忆存储格式不变，链接技能更新仍需主动开启。

支持正式发布的 DSH **0.2.2-rc.1 和 rc.2**，并保留文档列出的旧 Host 支持；不承诺兼容 alpha 或任意源码构建。详见[兼容性](../reference/compatibility.md)。

审查预算是每次模型响应的上限，并非固定 token 消耗。Host 不一定按模型输出能力自动裁剪该参数。如果审查模型或网关的输出上限低于 16,384，请将**每次模型输出 token 上限**（`idleReview.maxTokens`）显式设置为其支持的值，例如 4,096。已有显式配置会保留；本版本没有新增自动重试或限额适配。
