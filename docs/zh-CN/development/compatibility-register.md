# 兼容登记表

**简体中文** | [English](../../en/development/compatibility-register.md) | [文档中心](../README.md)

有些代码只为让旧的东西继续可用而存在：早期 dsh-mnemon 保存的设置或数据、较旧的 DSH，或基于早期 SDK 构建的插件。下表每一行写明这段代码在哪里、为什么存在，以及满足什么条件后可以移除。用户能看到的部分见[兼容性与升级](../reference/compatibility.md)。

请保持登记表最新：加入这类代码的改动同时加入它的一行，移除它的改动同时删去这一行。移除会改变用户、已保存的 profile 或基于公开 SDK 的插件所见内容时，需要写进发布说明；公开导出只在主版本发布中移除。
