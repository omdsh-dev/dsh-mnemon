# v0.5.51 发布验收

**简体中文** | [English](./README.md)

2026 年 11 月 22 日，在 9 个已发布的 DSH 版本中，通过**插件 → 添加插件**全新安装候选版，并在另一份 v0.5.50 配置中通过**记忆系统 → 状态 → 检查版本 → 更新**完成升级。

`0.2.0-rc.2`, `0.2.1-rc.2`, `0.2.1-rc.3`, `0.2.1-rc.5`, `0.2.2-rc.1`, `0.2.2-rc.2`, `0.2.2-rc.3`, `0.2.2-rc.4`, `0.2.2-rc.5`

18 个测试配置均匹配 19 个锁定包，并逐一核对三个候选包的 143 个文件和可执行权限。所有升级配置重启 DSH 后仍能读取升级前的置顶测试记忆，源数据和 Markdown 投影的 SHA-256 摘要均与升级前一致。

DSH `0.2.2-rc.5` 完整回归通过 2,906 项测试，9 项按条件跳过。Starter 压缩后为 627,093 字节，解包后为 2,656,160 字节，低于 3,000,000 字节上限。[候选制品摘要与结果](./validation.json)
