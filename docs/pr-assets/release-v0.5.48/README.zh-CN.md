# v0.5.48 发布验收

**简体中文** | [English](./README.md)

2026 年 11 月 18 日，在八个已发布的 DSH 版本上分别从**插件 → 添加插件**全新安装 v0.5.48，并在独立的 v0.5.47 Web 环境中从**记忆系统 → 状态 → 版本 → 更新**升级。八组升级完整重启后均可读到原有置顶记忆，三个 Runtime 文件的 SHA-256 均与升级前一致。

| 宿主系列 | 实测版本 |
| --- | --- |
| DSH 0.2.0 | rc.2 |
| DSH 0.2.1 | rc.2、rc.3、rc.5 |
| DSH 0.2.2 | rc.1、rc.2、rc.3、rc.4 |

16 个环境均匹配 19 个锁定版本。三个变更包在每个环境共 154 个文件，文件清单、内容和执行权限均与候选制品一致。rc.4 已安装宿主回归测试通过 2,858 项，另有 9 项条件跳过。

rc.4 上首次运行 Headless 脚本时沿用了默认的 v0.5.29 作为升级起点。这个旧 Starter 在安装候选包之前就未能初始化 Runtime 数据。仍在使用 v0.5.29 的用户应先在原有 DSH 上更新 Mnemon，再切换宿主。表中网页升级的起点均为 v0.5.47。

验收使用 macOS arm64、Node 24.22.2、pnpm 10.13.1、隔离 Web 环境及合成数据。回环测试仓库提供三个候选包，其余依赖取自 npm。[验证数据](./validation.json)列出候选包 SHA-512 和体积，[逐文件验收记录](https://github.com/omdsh-dev/dsh-mnemon/releases/download/v0.5.48/v0.5.48-acceptance.tar.gz)提供包清单、文件列表及 SHA-256 校验值。
