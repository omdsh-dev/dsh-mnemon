# 空闲审查限额持久化设置

在隔离的本地测试环境中，以 1440 × 1000 视口截取真实 DSH WebUI 设置对话框。设置图片直接截取实际对话框，状态图片截取工作区标题与状态区域；均未修改像素。环境使用合成数据和本地脚本模型，没有调用外部模型，也没有修改个人 Desktop 配置。

- [默认关闭](settings-default-off.png)：可选的持久化开关初始关闭。
- [启用后](settings-enabled.png)：通过界面启用后的状态；刷新浏览器后仍保持启用。
- [会话状态](status-session-attempts.png)：启用持久化并完成一个合成父会话回合后，真实工作台显示已用 0 / 1 次、恢复 0 次。截图包含工作台顶部与状态卡片，避开存储路径。
- [界面验证记录](ui-verification.json)：已去除环境敏感信息的截图检查结果。

界面中的模型名称来自 DSH 测试配置，实际执行由本地脚本响应替代。这些截图证明设置与状态的实际显示效果和配置保存行为；会话重开后的准入、失败计次、损坏状态处理及多进程竞争由独立的 Host、生命周期和存储自动化测试验证。
