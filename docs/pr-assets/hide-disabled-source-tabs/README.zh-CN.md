# 隐藏已关闭 Source 的标签页

[English](./README.md)

使用本分支的本地构建、真实 DSH 0.2.1-rc.2 WebUI 和隔离的 `scripts/serve-e2e.mjs --docs-demo=zh-CN` 夹具。页面中的 Lumen 档案与记忆均为虚构数据。关闭状态截图裁掉了下方的临时存储路径。

1. [开启](./enabled.png)：项目档案页面可选，共五份活跃档案和一份归档。
2. [关闭](./disabled.png)：在夹具配置中关闭 `mnemon-source-documents` 后重启。标签页消失，状态页仍说明组件已关闭，配置入口仍然可用。
3. [恢复](./restored.png)：重新开启同一组件并重启。标签页恢复，五份活跃档案和一份归档均保留。

截图验证真实浏览器中的持久组件开关。Vitest 另行验证无需重启关闭当前页面、拒绝已关闭页面的锚点、恢复标签顺序、通用管理页和独立聚焦页、内置三层的八种开关组合，以及第三方 Source 替代已关闭内置 Source 的兼容性。已开启但未能运行的 Source 保留诊断标签页。未使用私人数据、真实模型请求或用户个人配置。
