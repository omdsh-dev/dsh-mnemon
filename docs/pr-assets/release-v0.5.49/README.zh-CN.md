# v0.5.49 发布验收

**简体中文** | [English](./README.md)

2026 年 11 月 20 日，在 9 个正式 DSH 宿主上通过**插件 → 添加插件**新装候选包，并在独立的 v0.5.48 配置中通过**记忆系统 → 状态 → 版本 → 更新**升级。

`0.2.0-rc.2`, `0.2.1-rc.2`, `0.2.1-rc.3`, `0.2.1-rc.5`, `0.2.2-rc.1`, `0.2.2-rc.2`, `0.2.2-rc.3`, `0.2.2-rc.4`, `0.2.2-rc.5`

18 个配置均匹配 19 个固定包版本。每个配置的 126 个候选包文件均与打包内容和可执行位一致。升级并完整重启后，WebUI 仍可读取预置的合成固定记忆，三个 Runtime 文件的 SHA-256 与升级前相同。

DSH 0.2.2-rc.5 完整宿主测试通过 2,888 项，9 项按条件跳过。[核验记录](./validation.json)包含候选包校验值、大小和测试环境。
