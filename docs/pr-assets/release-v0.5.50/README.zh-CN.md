# v0.5.50 发布验收

**简体中文** | [English](./README.md)

2026-11-20 在 9 个正式发布的 DSH 版本中，通过**插件 → 添加插件**全新安装候选，并在各自独立的 v0.5.49 Profile 中通过**记忆系统 → 状态 → 检查版本 → 更新**完成升级。

`0.2.0-rc.2`, `0.2.1-rc.2`, `0.2.1-rc.3`, `0.2.1-rc.5`, `0.2.2-rc.1`, `0.2.2-rc.2`, `0.2.2-rc.3`, `0.2.2-rc.4`, `0.2.2-rc.5`

18 个 Profile 都匹配 19 个锁定的包版本，并核对了五个候选包中的 197 个文件及其执行权限。完整重启后，各升级 Profile 都保留了用于验证的固定运行时记忆，`memories.json`、`MEMORY.md` 和 `USER.md` 的 SHA-256 与升级前一致。

DSH `0.2.2-rc.5` 的已安装宿主回归通过 2,891 项，另有 9 项条件跳过。[验证记录](./validation.json)列出了候选提交、测试环境和包的摘要。
