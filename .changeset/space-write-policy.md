A Memory Space can be **Read only** (#434): choose it under **Writes** in the space's **Edit** dialog, and its card says so. DSH still recalls it as before, and no write from DSH reaches its Provider: remember, a batch of memories, forget, link, the task Agent's writes, MEMORY.md and Document index archival and merging into it are refused before the Provider is called, with an error that names the space. A read-only Mnemon Native space also keeps its Store and takes no vectors from **Fill in**. The choice follows the namespace, so a space made by hand for the same bank, a rediscovery, a reconnect or switching a space on gains no write. A write that names no space goes to the one active writable space and never to a read-only one; with every space read only, a full MEMORY.md archives to the local archive file. The choice is kept for the data directory in `state/memory-provider-write-policy.json`; if that file cannot be read, every space is read only and recall keeps working. The Source management operation `body-write-policy` (`{ memoryBodyId, policy: 'writable' | 'read-only' }`, confirmed) sets it, the page client's `setWritePolicy` calls it, and a read-only space carries `writePolicy: 'read-only'` in the directory and status. Spaces without the choice behave as before.

记忆空间可以设为**只读**（#434）：在空间的**编辑**对话框中，于**写入**下选择，卡片上会显示。DSH 仍照常召回它，但不会有 DSH 的写入到达它的 Provider：存入、批量存入、遗忘、链接、任务 Agent 的写入、MEMORY.md 与文档索引的归档，以及合并进该空间，都会在调用 Provider 之前被拒绝，报错写明是哪个空间。只读的 Mnemon Native 空间还会保留它的 Store，**补齐**也不会为它生成向量。设置跟随命名空间：为同一个 bank 手动创建的空间、重新发现、重新连接或打开开关都不会带来写入。未指定空间的写入进入唯一一个已激活且可写的空间，不会写进只读空间；所有空间都只读时，写满的 MEMORY.md 归档到本地归档文件。设置按数据目录保存在 `state/memory-provider-write-policy.json`；该文件无法读取时，所有空间都按只读处理，召回照常。Source 管理操作 `body-write-policy`（`{ memoryBodyId, policy: 'writable' | 'read-only' }`，需确认）负责设置，页面客户端的 `setWritePolicy` 调用它，只读空间在目录与状态中带有 `writePolicy: 'read-only'`。没有设置的空间行为不变。
