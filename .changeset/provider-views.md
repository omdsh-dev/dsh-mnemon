A Provider can show what it keeps beside its memories. A space whose Provider declares views gets **Browse** on its card: `files` views walk the Provider's own hierarchy and preview images and text, and `changes` views list what the Provider itself changed, each with its before and after. Providers declare `views` in their descriptor and serve them through `view()`; the Source reads them for the page with the management read `provider-view` (`{ memoryBodyId, view, uri? }`) and keeps only the declared shapes, bounded in size. A Provider's status can also report the vendor's own DeepSeek Harness plugin running beside it (`integration`: package, version, effective automatic recall and capture, connection without credentials, whether it serves the space's namespace, `state` and up to six notes). The card names that plugin, and **Browse** shows it in full, saying that its tools, recall and capture run on their own. Where it captures into the space's own namespace and dsh-mnemon could still write there, the card suggests making the space read only for dsh-mnemon; its **Make read only** button sets the space's write policy (#434) only when pressed. Providers recognize their vendor through `profile` on their runtime context: `service(name)` returns a running service read only, and `rows()` lists the profile's plugin rows with secret-looking keys removed. Providers that declare no views and report no plugin are unchanged.

Provider 可以展示它在记忆之外保存的内容。Provider 声明了视图的空间，卡片上会出现**浏览**：`files` 视图浏览 Provider 自己的层级，并预览图片和文本；`changes` 视图列出 Provider 自己做出的改动，每项都可展开查看改动前后。Provider 在描述中声明 `views`，并通过 `view()` 提供内容；Source 通过管理读取 `provider-view`（`{ memoryBodyId, view, uri? }`）为页面读取，只保留声明的结构并限制大小。Provider 的状态还可以报告与它并存的厂商官方 DeepSeek Harness 插件（`integration`：包名、版本、实际生效的自动召回与自动捕获、不含凭据的连接、是否服务于该空间的命名空间、`state`，以及至多六条说明）。卡片会写明这个插件，**浏览**中显示完整信息，并说明它的工具、召回与捕获自行运行。当它会把内容捕获进该空间自己的命名空间、而 dsh-mnemon 也仍可能写入时，卡片会建议把空间设为对 dsh-mnemon 只读；只有按下**设为只读**按钮时才会设置空间的写入策略（#434）。Provider 通过运行时上下文中的 `profile` 识别自己的厂商插件：`service(name)` 以只读方式返回正在运行的服务，`rows()` 列出配置中的插件行，并去掉看起来像密钥的字段。没有声明视图、也不报告插件的 Provider 行为不变。
