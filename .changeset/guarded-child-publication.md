Install delegated memory guards, continuation recovery and lifecycle bindings before ordinary Agent creation observers. This prevents a short-circuiting observer from skipping required setup and failing idle reviews or explicit memory writes, while retaining exact child ownership and scoped tool restrictions.

在普通 Agent 创建监听器之前安装委托记忆任务的守卫、续聊恢复和生命周期绑定，避免监听器提前结束事件分发时跳过必要初始化，导致空闲审查或主动记忆写入失败；保留精确子 Agent 身份校验和工具权限限制。
