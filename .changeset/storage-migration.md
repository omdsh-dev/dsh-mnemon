Memory can now move to another data directory without leaving Mnemon. The settings page's **data directory** field opens the shell's own directory chooser where the shell has one and stays typable where it does not, and a directory that differs from the one memory uses now is offered as a move: the Host reads the source first and the confirmation dialog names both paths, the files and bytes it would carry, and the fact that nothing is deleted before every file verifies. Moving is a Host operation of its own, `storage-plan` and `storage-migrate` on the Pack channel: the plan reports what the source holds, whether the target already carries Mnemon data, and whether the two roots share a device, and a move refuses a target that is occupied, nested or identical to the source, or a filesystem root on either side. A move on one device is a single rename; across devices the tree is copied and every file is read back and compared by SHA-256 before the source directory is removed, so a failed verification leaves the original untouched. A completed move records the new path as the `custom` data directory and rebuilds the Host's runtime on it, so the page, Pack backup and every component read the new directory without a restart, and a profile that cannot be written refuses the move before any file is copied. Choosing **Default** now stops memory from *using* a custom directory instead of forgetting which one was chosen, so the choice can be taken back. The components that keep their data in the directory are still named above it, each opening its own page.

记忆现在可以迁移到另一个数据目录而不用离开 Mnemon。设置页的**数据目录**字段在宿主提供目录选择器时会打开它，没有时仍可手动输入；当所选目录与当前使用的目录不同时，会给出迁移选项：Host 先读取原目录，确认弹窗会说明新旧两个路径、将迁移的文件数与字节数，以及「全部文件校验通过前不会删除任何数据」。迁移本身是 Host 的一个独立操作，即 Pack 通道上的 `storage-plan` 与 `storage-migrate`：计划报告原目录的内容、目标是否已存放 Mnemon 数据、两个根是否在同一设备上；目标已占用、与源相互嵌套或完全相同、以及任一侧是文件系统根目录时都会拒绝迁移。同一设备上的迁移是一次 rename；跨设备时先复制整棵树，逐文件读回并比对 SHA-256 通过后才删除原目录，因此校验失败时原目录保持原样。迁移完成后会把新路径记为 `custom` 数据目录并据此重建 Host 运行图，因此页面、Pack 备份与各组件无需重启就读到新目录；设置档案不可写时，会在复制任何文件之前拒绝迁移。选择**默认**现在只是让记忆不再*使用*自定义目录，而不再忘记选过哪一个，因此这个选择可以撤回。把数据放在该目录里的组件仍列在它上方，每个都可以打开自己的页面。
