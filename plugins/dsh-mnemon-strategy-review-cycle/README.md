# Periodic review

Optional `review` contribution to the workspace Strategy. This policy is pure guidance; its Source owns data and lifecycle state, and the Host authorizes operations. It neither writes memory nor starts tasks during composition.

Configure through the owning DSH Entry or Memory System settings. Disabled by default. Run `pnpm verify` independently.

## 简体中文

定期审查增强只向工作区策略贡献纯策略数据，不在组合过程中写数据或启动任务。状态属于 Source，操作由 Host 授权。默认关闭，可独立配置和验证。
