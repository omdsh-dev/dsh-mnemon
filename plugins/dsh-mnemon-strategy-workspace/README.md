# Workspace Strategy

An optional Strategy that selects public Source capabilities, allocates one shared budget and accepts independently evaluated context policies. It supports unfamiliar Source roles and separately scoped instances without a business-role allowlist. Timing and workflow guidance belong to its enhancements.

Contributions use `mnemon-context-policy/v1` through the public extension SDK. Core verifies their prerequisites and binds instructions after Source projection succeeds. The default three-tier Strategy remains the installation default. See [context access](../../docs/en/development/context-access.md) for the contract.

Run `pnpm verify` for standalone checks.
